# Bank Account Management System

The **Bank Account Management System** is a MySQL database project designed to manage customer and bank account information efficiently.

The project contains two main tables: **Customers** and **Accounts**. The Customers table stores customer details such as customer ID, name, and city. The Accounts table stores account information such as account ID, customer ID, account type, and account balance.

A **Primary Key** is used to uniquely identify each customer and account, while a **Foreign Key** establishes a relationship between the Customers and Accounts tables. The project also demonstrates **AUTO_INCREMENT**, **DECIMAL data types**, and inserting sample records.

### Main Features
- Store customer details
- Store multiple bank accounts for customers
- Maintain account types such as Savings and Current
- Store account balances
- Establish a relationship between customers and accounts using a Foreign Key
- Perform basic database operations using MySQL

### Technologies Used
- MySQL
- MySQL Workbench

### Concepts Covered
- CREATE TABLE
- INSERT INTO
- Primary Key
- Foreign Key
- AUTO_INCREMENT
- DECIMAL data type
- One-to-Many relationship.
